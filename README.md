## Project Overview
Clean City is a non-profit organisation that keeps communities clean
through recycling initiatives and supports people in need through
community programmes. This project is a website built to represent
Clean City online, allowing visitors to learn about the organisation,
its services, and how to get involved through volunteering, donations,
or enquiries.

## Website Goals and Objectives
- Raise awareness of Clean City's recycling and community support work
- Provide clear information about the organisation's history, mission,
  and team
- Give visitors an easy way to make enquiries or get involved
  (volunteering, donations, partnerships)
- Present a clean, accessible, and easy-to-navigate site structure

## Key Features and Functionality
- Responsive multi-page website (Home, About, Services, Enquiry, Contact)
- Consistent header with logo and navigation across all pages
- Hero section with video introduction on the homepage
- Dedicated Services page detailing recycling and community support offerings
- Enquiry page with a contact form plus alternative ways to get involved
- Footer with organisation info, quick links, contact details, and social
  media links on every page
- Semantic HTML structure (`header`, `nav`, `main`, `section`, `article`,
  `footer`) for accessibility and SEO
